# ✅ **JavaScript Miscellaneous Problems**

---

## **1. Remove duplicates from an array**

**Problem:**
Given an array, return a new array with duplicates removed.

**Example:**
Input: `[1, 2, 2, 3, 4, 4]`
Output: `[1, 2, 3, 4]`

---

## **2. Count character frequency in a string**

**Problem:**
Return an object where keys are characters and values are frequencies.

**Example:**
Input: `"banana"`
Output: `{ b:1, a:3, n:2 }`

---

## **3. Reverse words in a sentence**

**Problem:**
Reverse the **order of words**, not the characters.

**Example:**
Input: `"hello world from js"`
Output: `"js from world hello"`

---

## **4. Flatten a nested array**

**Problem:**
Flatten an array of arbitrary depth.

**Example:**
Input: `[1, [2, [3, [4]]]]`
Output: `[1, 2, 3, 4]`

---

## **5. Check if a string is a palindrome**

**Problem:**
Return `true` if the string reads the same forward and backward.

**Example:**
Input: `"racecar"` → `true`
Input: `"hello"` → `false`

---

## **6. Find the longest word in a sentence**

**Problem:**
Return the longest word.

**Example:**
Input: `"JavaScript is awesome"`
Output: `"JavaScript"`

---

## **7. Implement a debounce function**

**Problem:**
Create `debounce(func, delay)` that delays function execution until no new calls happen within `delay` ms.

---

## **8. Find the second largest number in an array**

**Problem:**
Return the second highest value.

**Example:**
Input: `[10, 5, 20, 8]`
Output: `10`

---

## **9. Group objects by property**

**Problem:**
Group items in an array by a key.

**Example:**
Input:

```js
[
  {type: "fruit", name: "apple"},
  {type: "veg", name: "carrot"},
  {type: "fruit", name: "banana"},
]
```

Output:

```js
{
  fruit: ["apple", "banana"],
  veg: ["carrot"]
}
```

---

## **10. Implement a simple event emitter**

**Problem:**
Support `.on(event, callback)` and `.emit(event)`.
